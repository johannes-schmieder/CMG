# SCC2 diagnostics report

This report is generated from the immutable second-study runs described in
[`benchmarks2.md`](../../benchmarks2.md). Reduced CSV/JSON files remain in Git;
complete raw logs, profiler output, SGE accounting, and receipts are published
as a checksummed release asset after validation.

Run `benchmarks/scc2/analysis/reduce.py` on accepted local run copies before
compiling `benchmarks2.tex`. The generated PDF belongs at
`output/pdf/benchmarks2.pdf`.
